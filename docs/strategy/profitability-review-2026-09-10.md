## 二、盈利诊断：瓶颈不是产品，是「转化」与「信任」

**核心事实：124 个免费用户 → 0 付费，转化率 0%。** 这不是"还没开始有流量"，是漏斗底部塌了。预测类产品在没证明自己准之前，付费是反直觉的。

按可疑度排序的三个根因：

1. **支付链路可能根本没通。** PayPal `_xclick` + IPN 需要你在 PayPal 后台把 IPN 整体开关打到"接收"。若未开，即使有人付款，服务器收不到回执 → **无法自动开通 → 用户付了钱也没拿到权限**（这会造成退款/投诉，比"没人买"更伤）。当前 0 paying 无法区分"没人尝试"还是"尝试了但链路断"。

2. **价值证明缺失。** 准确率 0 verified、Brier=0.250（恰好等于随机基线）。产品对外宣称"可验证的概率场"，但**站内没有任何一处向用户证明它准**。信任 = 转化的前提，现在是空的。

3. **受众与收单方式错配。** 最大的 SEO 面是中文 `/tuivan/*`（88 条 sitemap 里一大半是中文页），目标人群是中国用户；但收单只有 PayPal（需双币卡）。中文流量几乎无法转化。

次要因素：免费额度（5 次/天）偏松，缺"价值时刻"的升级触发；付费钩子以订阅为主，而新用户信任未建立时订阅门槛过高。
