# OracleMind 项目独立评估（用户视角 / 竞品对标 / 照片功能 / 设计方向）

> 评估日期：2026-08-09
> 评估者：以"非用户"身份走查 + 竞品研究（Co-Star / The Pattern / AURA / Life Insight / FaceVibe）
> 目的：找出待改进项、评估照片分析功能可行性、判断设计风格是否匹配西方用户

---

## 1. 执行摘要（Verdict）

**项目定位确认：面向外国人（英语为主，日/韩为辅）的"概率场推演"产品。** 证据：next-intl 以 `en` 为源语言；支付用 Creem（国际收单）；SEO 落地页（horoscope/zodiac/compatibility）全英文；metadata locale `en_US`。

**总体判断：技术闭环与变现层已就绪，真正缺口在"增长飞轮"与"视觉一致性"，不在算法本身。**

Top 3 优先级：
1. **P0 — 修掉用户可见的"四柱"泄漏 + 统一配色**（踩红线 + 视觉打架，低成本高回报）。
2. **P0 — 做一张"可截图分享的能量卡"**（当前分享/导出功能存在但不够"scroll-stopping"，这是西方竞品的增长引擎）。
3. **P1 — 新增"照片/视觉共振"推演域**（借西方 Aura 照片病毒机制，用"能量基调/推演原型"框架承接，不暴露五行八卦）。

## 2. 竞品玩法研究（西方"推演/神秘学"赛道，非算命站）

| 产品 | 核心玩法 | 设计语言 | 增长/变现 | 可借鉴点 |
|---|---|---|---|---|
| **Co-Star** | NASA 星历 + AI，每日"Power/Trouble"、好友星盘对比、毒舌文案 | 极简黑白、大字留白、杂志感排版 | 免费+订阅 $9.99/月；几乎零投放，靠用户晒每日运势截图自然增长 | **分享即增长**：每日一句可截图转发；好友对比社交闭环 |
| **The Pattern** | 出生图→长文心理画像、"Timing"周期、Bonds 关系 | 柔和、文字重、易读 | 免费+Go Deeper $29.99/季 | "周期/时机"叙事（对应本项目"周期起伏"） |
| **AURA – Read Your Energy** | 自拍→AI 读"能量/气场"，输出 Aura Score 0–100 + 原型 + 可分享卡 | 极简、鲜艳渐变卡 | 内购（无注册） | **照片→能量卡→社交分享** 的完整闭环 |
| **Life Insight** | 上传手掌照片→AI 看手相；"精神动物"玩法 | 趣味、AI 图像 | 订阅周 $1.99–年 $39.99；**半年吸金 $176 万**，收入集中在英/澳/加/美 | 照片+玄学在**西方市场已验证可变现** |

**关键洞察：**
- 西方跑通的"照片分析"**不说五行八卦**，而是用 **Aura / Energy / Vibe / Color / Archetype / Spirit Animal**。这些词在西方 Z 世代语境里有天然传播力（#aurareading 千万级播放）。
- 国内"照片+周易八卦五行"能火，是因为**中国文化语境成立**；原样搬给老外会失去锚点。应借**机制**（上传→生成→分享），不借**术语**。
- 竞品增长几乎都靠**一张可截图分享的卡片**，而非功能本身。

## 3. 当前项目 Fresh-eyes 审计

### 3.1 配色两套体系打架（视觉一致性问题）
- `globals.css` 把设计系统定义为 **实验青 hue 180 + 古铜金 hue 50**（"实验室冷感深墨青"），并显式注释"五行配色降饱和度匹配冷感"。
- 但组件里**硬编码了紫色 hue 280/300**，与 token 体系冲突：
  - `src/app/domains/page.tsx:161` 标题 `text-[oklch(0.85_0.01_280)]`（紫）
  - `src/components/modules/tuivan-chart-display.tsx:180` `oklch(0.45_0.02_265)`（紫）
  - landing hero 渐变用 `oklch(0.55_0.14_280)`→`oklch(0.70_0.16_300)`（紫）
- **结论**：要么全转青/铜（强化"概率实验室"身份），要么选一个紫色作唯一点缀色并纳入 token。**现在两套并存 = 看起来像两个产品拼在一起。**

### 3.2 中文泄漏（含红线风险）⚠️
项目红线：用户可见禁用「八字/天干日主/四柱/十神/用神/大运/流年/命理/算命」。当前仍有泄漏：
- **`src/app/tuivan-chart/page.tsx:101`** 用户可见标题：`个人推演图谱 · 推演结构（四柱）` —— **"四柱"直接暴露给英文用户，踩红线。必须改。**
- `src/app/page.tsx:578` 英文 UI 里混入 `推演结构推算 + probability analysis`（中英混排）。
- `src/app/page.tsx:421` `推演图谱 & Deep Insight: Birth info`（中英混排）。
- `src/app/layout.tsx:42` meta description 硬编码中文 `古典哲学框架` —— 会出现在英文搜索/社交预览里。
- `src/components/modules/v3/landing-page-v3.tsx:287` 导航 `推演域`（英文站露出中文词）。
- `src/app/page.tsx:1116` 英文 hero 里 `1,000-year-old 古代推演规则`（中英混排，虽含"古典"叙事但整体不专业）。
- `src/components/modules/v2/streaming-simulation-panel.tsx:462` `推演结构（四柱）`（若该 v2 组件仍在渲染则泄漏）。

**注**：`src/lib/ai-provider.ts`、`bazi-engine.ts`、`classical/*`、`lab-chains.ts` 里的八字/五行/四柱均为**内核 substrate（双轨制）**，用户不可见，合规，不需改。

### 3.3 最大增长缺口：没有"可截图分享的能量卡"
- 现有 `share/[id]` 与 `export/[id]` 能生成报告，但**不是为社交截图设计的"scroll-stopping"卡片**（无强视觉锤、无分数焦点、无品牌水印、无"这是我的能量"句式）。
- 竞品（AURA/FaceVibe）靠一张卡在 TikTok/IG 自发传播。**这是目前最该补的增长飞轮。**

### 3.4 缺照片输入
- 当前仅文本 / 出生信息输入。照片是西方已验证的增长黑客（见 §2）。

### 3.5 缺"日常仪式 + 社交"循环
- 有 daily-forecast，但**无 streak（连续天数）/ 每日一句可截图 / 好友对比**。Co-Star 靠"每天一条"养成习惯并自然分享；本项目缺这个钩子。

### 3.6 文案语调
- 主 hero "Ask Anything. Get a Probability." 方向对（去玄学化、强调概率）。但中英混排与"lab/实验"措辞偏冷，缺少 Co-Star 那种"被看见、被理解"的情绪钩子。

## 4. 照片分析功能评估（用户核心诉求）

### 4.1 机制借鉴 —— 值得做，且已验证
- 西方"照片→能量/气质→分享卡"模型已被 AURA / Life Insight / FaceVibe 验证可变现。**你看到的"英文照片分析传播力度大"是真实的**（#aurareading 千万级播放；Life Insight 半年 $176 万）。
- 国内"照片+周易八卦五行"的**生长逻辑**可借鉴：**低门槛上传 → 即时生成个性化报告 → 强分享欲**。但**内容映射必须西化**。

### 4.2 文化适配 —— 关键修正（独立判断）
- **不要**把"五行/八卦"直接暴露给西方用户：老外无此文化锚点，且 App Store 对"面相/从脸读性格"（physiognomy）敏感，FaceVibe 的"从脸测祖源"已游走在伦理/审核边缘。
- **要**用项目已有框架承接：`能量基调 / 推演原型 / 关系维度 / 概率场`。照片分析对外叫 **"Visual Resonance（视觉共振）/ Energy Reading（能量解读）"**，输出：
  - **Energy Color（能量色）**——对应 Aura 的七色，内部可映射五行但**不写"五行"二字**；
  - **Archetype（推演原型）**——对应"十大推演原型"；
  - **Probability Signature（概率签名）**——一张图映射到当前概率场。

### 4.3 技术路径（可行性）
- 复用本地 `qwen3.6-vision` 或云端多模态 LLM：提取**主色调 / 构图能量 / 光影 / 表情气质** → 映射到"共振画像"。
- 内核双轨：视觉特征 →（内部）五行/八卦 substrate 计算 →（对外）能量基调/原型文案。**substrate 不触红线，对外全用推演话术。**
- 输出一张**生成式分享卡**（见 4.5）。

### 4.4 互动化（用户要的"互动似的"）
- 做 **"Resonance Tuner（共振调谐器）"**：用户上传照片得到基础能量卡后，可拖动滑块（如"如果我把能量色调暖一档""如果周期进入上升期"）→ 概率场实时重算并重绘卡片。
- 这把"一次性的玄学结论"变成"可玩耍、可分享、可再来一次"的互动，提升留存与分享率。

### 4.5 变现与落地
- 作为新推演域 **"图像推演 / Visual Resonance"** 接入现有 `lib/domains` 注册表：
  - 免费：生成预览卡（带水印，引导分享）；
  - 积分/订阅：解锁深度解读 + 高清无水印分享卡 + 调谐器。
- 复用现有 Creem 积分包 / 订阅，无需新建支付。

### 4.6 伦理红线（必须守住）
- **只做"能量/气质/审美共振"，绝不做"从脸判性格/命运/健康"**。避免 physiognomy 反弹与平台下架风险。
- 分享卡加 disclaimer："For entertainment & self-reflection, not a diagnosis."

## 5. 设计风格评估与方向建议

**是否针对外国人**：是。设计应按西方审美打磨。

**当前风格**："实验青 + 古铜金 + 数据网格 + 扫描线 + 粒子" = **科幻研究实验室**调性。这其实是个**有差异化的定位**（避开紫水晶球俗套），但当前被紫色点缀稀释、显得"既科技又玄学"的混乱。

**三个方向（含我的推荐）：**

| 方向 | 描述 | 优点 | 风险 |
|---|---|---|---|
| A. 全量"概率实验室" | 只留青/铜，去紫；数据可视化主导；强调"AI 不是魔法" | 差异化强、贴合"不是迷信"红线、专业可信 | 偏冷，情绪分享力弱 |
| B. 现代神秘/疗愈 | 学 Co-Star 极简编辑风，留白多，单一暖金或紫作点缀 | 情绪强、易分享 | 同质化、差异化弱 |
| **C.（推荐）混合"精确神谕"** | 保留概率/推演身份（护城河+红线对齐），但执行更干净：统一青/铜、去紫；加编辑级留白；引入拉丁衬线体（Cormorant/Newsreader）做"古典智慧"触感；**分享卡作为美学主角** | 既差异化又精致、可截图传播 | 需克制，别回到混乱 |

**具体设计动作：**
1. 统一 token：把 `domains/page.tsx`、`tuivan-chart-display.tsx`、hero 的紫色硬编码改为青/铜（或纳入 `--chart-5` 单一紫作唯一点缀并写进 token）。
2. 引入拉丁衬线体用于"古籍/古典"标题（现有 `Noto Serif SC` 仅中文，英文标题需 `Cormorant`/`Newsreader`）。
3. 重做分享卡：竖版 9:16，大号分数/能量色块 + 一句"这是我的概率场" + OracleMind 水印 + CTA，专为 TikTok/IG Story 截屏优化。
4. 留白与节奏：减少全屏扫描线/网格噪声，关键屏（hero、结果、分享卡）做呼吸感。

## 7. 结论

- **是否针对外国人**：是，且应按西方审美打磨。
- **整体设计是否要调整**：要，但方向不是"推倒重来"，而是**统一视觉语言 + 把分享卡做成美学主角 + 补照片与社交飞轮**。核心"概率场推演"身份保留（这是护城河，也符合红线）。
- **照片功能**：值得做，借西方 Aura 的"照片→能量卡→分享"机制，用"能量基调/推演原型"框架承接，**不暴露五行八卦**给老外；内核可用五行八卦作 substrate（双轨制合规）。
- **最大单一改进**：一张能截图传播的能量分享卡 + 修掉"四柱"泄漏。这两件做完，增长与合规同时上一个台阶。
