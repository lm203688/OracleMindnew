2. 跨板块三大共性断裂（必须连根拔）

  1. 冷启动死锁（M01∩M04∩M08）：校准证书、arena 飞轮、个人战绩都依赖 PredictionFeedback 真样本，而全仓 0 verified。→ 任何单板块优化都救不了，必须统一注入首批真实样本（arena 种子账号 + event-outcome-ledger 接 GDELT 回填）。
  2. 古典 substrate 残缺（M02）：5 书仅 2 本有真文本、节气为近似值 → 准确性硬伤 + "5 书并行"名不副实。→ 这是唯一会直接砸用户信任的准确性 bug，优先级高于所有"锦上添花"。
  3. 用户可见度塌陷（M06∩M07∩M08）：情报锚点、事前封存、个人校准曲线都是强信任资产，但没有进主 UI / 无公开页 / 空态未设计 → 差异化无法被用户感知，等于没有。
