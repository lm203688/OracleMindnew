## 二、定位关键段落原文（现有权威文档）

### CORE-GOALS.md（10-08 v1.0/v1.1，最高权威）

**一句话定位（L11）：**
> **OracleMind 是一个「公开记分板的概率场实验室」——用中国古代哲学框架提供结构假设，用现代数据科学提供可验证的测量，产出**可被第三方检验**的事件概率预测与个人倾向推演。**

**定位升级 v1.1（L13）：**
> **定位升级（v1.1，落实 D1）：OracleMind = 概率层（Probability Layer）+ 记分板（Scoreboard）。** 类比 Stripe = 支付层、Twilio = 通信层——**卖的不是预测，是「带信用背书的概率」（Certified Probability）。** 裸 LLM 只给数字，OracleMind 给带校准证书、共形区间、前瞻性封存 ID 的数字。稀缺性已从「谁能给概率」迁移到「① 人的参与与私有信息 ② 人机混合的增量 ③ 可被信任的长期记分板」。

**三大不可协商原则（L44-60）：**
1. **Automation First**：平台初次配置后无需日常人工干预即可运行、改进、增长。
2. **Precision Over Hype**：每一个输出都必须可验证；每个准度数字必须附带样本量+置信区间；样本量不足禁止宣称优于基线。
3. **Validation as Monetization**（v1.1 由 Monetization as Validation 更名）：先验证、再变现；被第三方持续验证的资产才是定价权来源；Money 不得污染校准数据纯度；核心玩法永久免费、无付费墙。

**合规红线（L72-82）：**
- **对外禁用词**：`八字` · `算命` · `fortune-telling` · `divination` · `horoscope`（作为产品名） · `塔罗` · `数秘` · **天干地支字面词**（甲木/乙木/丙火…）
- **允许的中性表述**：`概率场` · `倾向指数` · `能量基调` · `时间相位共振` · `决策支持` · `概率演化分析` · `推导图谱（Derivation Chart）`
- **已退役域**：占卜/塔罗/数秘/西方星座落地页（/horoscope/* 已 307 重定向）
- **运维要求**：`scripts/audit-public-terms.mjs` 必须保持 0 命中，每次上线前跑一次。

**北极星（L94，v1.1）：**
> **北极星（v1.1）：WAF（周活跃预测者）× 人均已结算预测数**（取代原 WAU-paid；理由：校准数据是唯一护城河，引入金钱会污染样本）

**数据策略（L107+）：**
> 数据即核心资产：累积的「预测 + 验证」数据集是平台的长期首要资产，支撑准度校准/个性化/竞争壁垒。
