# 板块 7 · 前瞻注册与反作弊（可验证性根基）

> 边界：`engines/commit-seal.ts`（73 行）+ `event-outcome-ledger.ts`（153 行）+ `automation/job-ledger.ts` + `calibration-backfill.ts`；API：`/api/oracle-core/mirror`、`/api/automation/calibration-backfill`。

## 一、流程合理性 / 走通性 / 人类使用习惯

**流程链路**：推演完成、结局未回填时 → `sealSimulation` 对"预测创建时规范载荷"（**刻意不含结局**）做 sha256 封存 → 存 `commitHash` → 结局揭晓后 `event-outcome-ledger` 按 `corpusId` 命中自动回写真实结局 → `job-ledger` 记录自动化运行审计。

**走通性 / 风险（最干净、最稀有的资产）**：
- `commit-seal` 实现**正确且严谨**：规范载荷 `{id,userId,type,seedInput,createdAt,scenarioOutcomes}` 按 path 排序后序列化，保证"同义载荷=同 hash（与字段顺序无关）"；`canonicalSealString` 让用户可独立复算验证未篡改。这正是预测市场"锁仓即公示、公示早于结果"的纪律。
- `event-outcome-ledger` 自动回写仅在 `corpusId` 命中（55 条语料）时发生——**覆盖窄**，但设计正确（不编造结局）。
- **未释放价值**：哈希只存自有 DB，未锚定去中心化时间戳；无公开验证页，用户/审计方看不到"这预测确实事前封存"。

**人类使用习惯**：可验证性是信任底层，普通用户无感直到"看到作弊证明"；应做公开验证页 + "本预测已事前封存"徽章。

**结论**：实现正确性 9/10，覆盖 3/10，用户可见度 2/10，独特性 9/10。

## 二、市场竞品与需求比较

| 参照 | 定位 | 关系 |
|---|---|---|
| OSF 预注册 | 学术研究事前注册 | 方法论同源，OracleMind 首用于"预测" |
| OpenTimestamps | 比特币免费时间戳 | 去中心化证明可借用 |
| 预测市场锁仓 | 公示早于结果 | 直接对标纪律 |

**需求**：AI 预测泛滥、信任稀缺，"可证明未事后篡改"是稀缺信任资产；**无消费级预测产品公开做此**，OracleMind 领先 1–2 年。

## 三、最新开源技术融合机会

- **OpenTimestamps**：把 commitHash 锚定比特币/以太坊时间戳，零成本去中心化证明（比仅存 DB 强）。
- **OSF / HashML / Model Cards**：预注册范式与可验证 AI 标准可对接。
- **JobRun 账本（已有）**：扩展为全链路不可变审计日志。

## 四、单板块提升方案

- **P1-①**：commitHash 锚定 OpenTimestamps（或以太坊 calldata），实现去中心化不可篡改证明。
- **P1-②**：做公开验证页（`/api/oracle-core/mirror` 已有） + "已事前封存"徽章，营销为"可证明不马后炮"。
- **P1-③**：扩大 `event-outcome-ledger` 触发面（接 GDELT 回填使更多事件可自动对账）。
- **P2**：把"可验证预测"作为独立品类对外发声，建立标准话语权。

**板块健康度评分（0–5）**：实现正确 5 · 覆盖 2 · 用户可见度 1 · 独特性 5 · 开源可融合 4 → **综合 3.4**
