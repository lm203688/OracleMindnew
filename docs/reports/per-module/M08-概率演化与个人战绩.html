板块 8 · 概率演化与个人战绩（校准追踪器）

边界：engines/streak.ts（47 行）+ prediction-feedback.ts（483 行）+ api/quality-evolution（Brier 聚合）+ api/feedback/* + /quality-evolution + /accuracy + /profile + /journal 页面。

一、流程合理性 / 走通性 / 人类使用习惯

流程链路：每日 streak（纯函数连续天数）→ 每次预测 recordPredictionFeedback → 结局 reportActualOutcome 打 Brier → quality-evolution 按日/月聚合 → 个人页展示校准曲线/战绩 → journal 反思。

走通性 / 风险：

  • streak 纯函数、逻辑正确（断档重置、同日不重复），可单测。
  • quality-evolution 用原生 SQL 聚合 PredictionFeedback，实现正确。
  • 全局瓶颈：一切依赖真实预测 + 结局——当前 0 verified，所有仪表盘是空态；空态 UX 未定义（显示"无数据"劝退）。
  • journal 存在但疑似与预测脱节（未确认是否挂 predictionId），反思难沉淀为校准信号。

人类使用习惯（本板块是最强消费差异化）：个人 Brier + 校准曲线像"判断力健身环"，streak 像打卡——强动机设计。但空场 + 无引导让首批用户看不到价值。竞品中无消费级"个人校准追踪器"，是空白。

结论：机制设计 8/10，实测走通 2/10，空态/引导 3/10，差异化 9/10。

二、市场竞品与需求比较

参照 定位 关系
超级预测员（私下追踪） 个人 Brier 文化 OracleMind 把它做成消费产品
健身/习惯 App（Keep/STREAK） 打卡动机 gamification 可借鉴
无直接竞品 消费级校准追踪 空白市场

需求：用户要"我变准了吗"的可视证据；这是 OracleMind 相对巨头的唯一消费级护城河（巨头不做个人记分板）。

三、最新开源技术融合机会

  • Recharts / visx：校准曲线、Brier 演化图（前端已可能用）。
  • PostHog：个人行为/留存分析，补空态引导。
  • Brier/calibration 工具：把 scientific-metrics 的指标做成可分享卡片。
  • 社交分享组件：战绩卡可分享对比（好友间"谁更准"）。

四、单板块提升方案

  • P0-①：设计强空态 + 引导式首批预测（引导用户先预测 10 条可验证事件，如体育/宏观），让曲线 72h 内有形。
  • P0-②：校准曲线设为个人页 Hero 特征，一句话"你比大众准 X%"。
  • P1-①：journal 关联 predictionId，反思反哺校准提示。
  • P1-②：战绩分享卡 + 好友对比，释放社交裂变。
  • P2：个人战绩与 arena 排行打通，形成"练习→证书→社交"闭环。
