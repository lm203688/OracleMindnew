# 板块 1 · 核心校准预测引擎

> 边界：`prediction-engine.ts` + `engines/calibration.ts` + `conformal-prediction.ts` + `forecast-guard.ts` + `scientific-metrics.ts`；API：`/api/predict`、`/api/predict-engine`、`/api/forecast`、`/api/prediction-accuracy`、`/api/public/accuracy`。

## 一、流程合理性 / 走通性 / 人类使用习惯

**流程链路**：`scenario-synthesizer`（中性/保守/乐观三情景概率）→ `modern-deep-analysis`（LLM 深析）→ `calibration`（经验贝叶斯收缩）→ `conformal-prediction`（Split-Conformal 区间）→ `forecast-guard`（`normalizeDistribution` 分位数交叉修复 + `climatologyBrier` 技巧分）。架构是**真实、正确、可单测**的，不是包装。

**走通性（已验证）**：
- 校准层是真实经验贝叶斯收缩：`sampleSize=0 → calibrated=0.5`（"我们不知道"），`K=20` 约 20 条验证才回复原始概率。零数据也安全，绝不伪造精度——行业罕见诚实。
- `conformal-prediction` 是真实 Split-Conformal，含有限样本 `ceil` 修正（ prior 报告已确认）。
- `forecast-guard` 做了两件硬核工程：① 概率分布合法性修复（对标 TimesFM `fix_quantile_crossing`，上游越界即回退均匀分布而非一堆 0）；② climatology 基线技巧分（修正了"固定 0.25 当随机基线"的经典错误，baseRate=0/1 时诚实返回 null）。
- **关键修复（2026-10-14 复扫确认）**：`science-layer.ts` 的逐次校准证书此前只读静态 `EVENT_CORPUS`（永远"无数据"=断链 #6），**现已改为优先读 `db.predictionFeedback` 真实验证样本**，EVENT_CORPUS 仅兜底。用户可见校准证书已接通真实飞轮。

**未走通 / 风险**：
- **冷启动仍是全局瓶颈**：生产环境至今 11 条预测、0 条 verified（actualOutcome 全空）。校准层永远收缩到 0.5，共形层没有校准集可 split——引擎架构完整但**实证处于冰点**。
- `calibration.ts` 的 `baseRate` 默认 0.5 是静态先验；类别基率未在线估计，长期会偏差。
- **人类使用习惯**：返回 `canClaimSkill:false` 是信任资产，但"我们给 50%"对付费用户感知价值低。三情景表述对小白偏复杂；缺一条"一句话结论 + 校准证书徽章"的主路径。

**结论**：架构 9/10，实证 2/10，人类主路径 6/10。

## 二、市场竞品与需求比较

| 竞品 | 定位 | 与 OracleMind 关系 |
|---|---|---|
| Metaculus | 纯信号预测社区（无金钱） | 直接竞品：它不做校准证书、不接古典 |
| Polymarket / Kalshi | 真金预测市场（美国） | 合规冲突（非博彩定位），不可直接照搬 |
| Good Judgment Open | 超级预测员训练 | 方法论标杆：Brier/校准文化 |
| ForecastBench | AI 预测评测榜 | 2026-10 带工具 AI(69.0) 已超人类顶级(68.6)——"给概率"被巨头商品化 |

**需求缺口**：巨头商品化的是"概率值"；**稀缺迁移到"可被信任的长期校准证书 + 个人记分板"**——正是本板块独有资产。但当前冷启动让证书无内容可显，差异化无法被用户感知。

## 三、最新开源技术融合机会

- **MAPIE**（BSD-3，PyPI）：工业级 Conformal Prediction，`MapieRegressor/MapieClassifier` 直接出分配/分类区间——可替换自研共形层或做交叉验证。
- **sklearn `CalibrationDisplay` / Isotonic-Platt**：把经验贝叶斯收缩升级为数据驱动的校准曲线（一旦有样本）。
- **Adaptive Conformal Inference (ACI, 2025 ScienceDirect)**：事件分布漂移时在线更新置信水平——比静态 Split-Conformal 更适合"未来事件"场景。
- **TimesFM 3.0 / Chronos-2**：只取它们的分位数输出喂给自研校准层（L2 路线），成本极低。

## 四、单板块提升方案

- **P0-①**（已 largely done）校准证书改读实时表 → 维持。
- **P0-②**：打通冷启动——arena 镜像 + `event-outcome-ledger` 自动回写先把 11 条 + 语料 55 条灌进 `predictionFeedback`，让证书/曲线 72h 内有真实数据。
- **P1-①**：引入 ACI 在线校准，替换固定 K 先验；类别基率改在线估计。
- **P1-②**：UI 主路径 = "一句话结论 + 校准证书徽章 + 三情景可展开"，降低小白认知负荷。
- **P2**：接入 MAPIE 做对照实验，验证自研共形层是否优于通用库。
