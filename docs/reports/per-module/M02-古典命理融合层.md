# 板块 2 · 古典命理融合层

> 边界：`lib/bazi-engine.ts` + `lib/classical/*`（12 文件）+ `engines/ancient-frame-features.ts` + `tendency-field.ts` + `mirror-engine.ts`；API：`/api/divine/[domain]`、`/api/tuivan/*`、`/api/horoscope/*`、`/api/zodiac/*`、`/api/compatibility/*`；页面：tuivan、horoscope、resonance、zodiac、compatibility。

## 一、流程合理性 / 走通性 / 人类使用习惯

**流程链路**：`bazi-engine`（确定性排盘：年/月/日/时四柱，天干地支/五行/藏干硬编码）→ `classical-orchestrator`（5 书并行 + RAG + GoT 学派共识 + 分歧检测）→ `classical-deep-analysis`（每书多维推理链）→ `classical-llm-enhancer`（白话解盘）。这恰是 **2026 玄学 App 市场胜出架构**（搜索证实：玄易/灵机均采用"硬编码排盘 + 大模型解盘"，规避 LLM 历法数学幻觉）。OracleMind 已自发对齐市场，结构正确。

**走通性 / 风险（重大）**：
- **古典 substrate 严重残缺（已实测）**：5 本古籍实体文本仅 **2/5** 就位——渊海子平 2467 行、三命通会 8780 行是真文本；**子平真诠 27 行、滴天髓 121 行、穷通宝鉴 53 行近乎空壳**。所谓"5 书并行验证"实际是 2 书真跑 + 3 书在空文本上"表演"。
- **节气边界为近似值**：`SOLAR_TERM_BOUNDS` 用固定月/日（如立春 2/4）判定月柱，未做天文精确计算。出生在立春前后 1–2 天的用户**月柱可能算错**——这是命理产品的致命准确性 bug。
- `classical-orchestrator` 产出 5 份报告 + 分歧分析，信息密度高但对小白**过载**；用户要的是一句可信叙事，不是 5 份互相打架的报告。

**人类使用习惯**：排盘准确 + 白话解盘是用户核心诉求，已满足方向；但缺"命理师人工兜底/咨询预约"闭环（竞品标配），且分歧未转化为"你该信哪派"的决策建议。

**结论**：架构方向 8/10，substrate 完整度 3/10，准确性 4/10，人类叙事 5/10。

## 二、市场竞品与需求比较

| 竞品 | 规模/模式 | 启示 |
|---|---|---|
| 灵机八字 | 生态整合（八字+紫微+风水+黄历+占卜+命理师预约） | OracleMind 缺生态与人工咨询桥 |
| 玄易 APP | 宣称"独家 AI 模型融合《三命通会》" | OracleMind **真有**三命通会 8780 行文本，资产被低估未营销 |
| 八字紫微排盘（小米） | 装机量型工具 | 纯工具无 AI，易复制 |
| 紫微斗数 AI（2026 交付 132 套） | 垂类工作室 SaaS | 垂类化趋势明确 |

**需求**：市场正从"小程序割韭菜"转向"专业级垂类模型 + 可解释 + 人工兜底"。OracleMind 的 GoT 分歧检测 + 三命通会真文本是差异化素材，但**空壳 3 书与节气 bug 直接削弱可信度**。

## 三、最新开源技术融合机会

- **lunar-typescript / lunar-java**：精确节气与干支计算（天文算法），替换近似边界，修复月柱 bug。
- **OCR + 古籍结构化**：对子平真诠/滴天髓/穷通宝鉴做版面 OCR + 段落切分，补齐 3 本空壳 substrate（成本低于重写）。
- **classical-knowledge-rag（已有）** 可升级为向量库 + 规则图谱双检索。
- **命理规则知识图谱**（OpenSPG / Neo4j）：把"格局/用神/旺衰"结构化，支撑 GoT 共识而非纯 LLM 自由发挥。

## 四、单板块提升方案

- **P0-①（准确性阻断）**：用 lunar-typescript 替换节气近似算法，加单测覆盖立春边界用例。
- **P0-②（substrate 补全）**：OCR 补齐 3 本空壳书，使其从"27/121/53 行"到完整；否则"5 书并行"是伪命题。
- **P1-①**：分歧检测升级为"决策建议"——高共识直接给结论，低共识说明不确定，而非堆 5 份报告。
- **P1-②**：加"命理师人工咨询"桥（对接预约/分成），对齐竞品变现路径。
- **P2**：把三命通会真文本作为营销资产对外讲"真·古籍融合"，区别于套壳竞品。
