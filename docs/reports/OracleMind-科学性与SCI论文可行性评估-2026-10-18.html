1. 科学内核体检（逐文件，带证据）

1.1 校准层 calibration.ts（92 行）——⭐ 正确

  • 经验贝叶斯收缩 shrink = n/(n+K)，calibrated = base + (raw-base)*shrink，公式标准且无偏。
  • 零数据诚实降级：n=0 → calibrated=0.5（"我们不知道"），绝不伪造精度。这是论文最该强调的科学纪律。
  • 纯函数、可单测、无副作用。代码质量达发表级。
  • ⚠️ 风险：K=20 是超参数拍定，论文里需说明取值依据（或做敏感度分析）。

1.2 共形预测 conformal-prediction.ts（327 行）——⭐ 正确且有理论自觉

  • Split Conformal 二元预测集，引用 Vovk 1999 / Lei 2018 / Vovk-Lei-Wasserman 2022，文献到位。
  • 有限样本修正用 ceil((n+1)*q) 而非 ceil(n*q)——这是 Split Conformal 的正确下界，说明作者懂分布无关保证的边界条件。
  • n<3 拒绝给保证、空集退化回全集——诚实降级贯穿始终。
  • 与 Bootstrap CI 的定位区分写得清楚（一个答"整体精度"、一个答"单次可靠"）。

1.3 科学指标 scientific-metrics.ts（366 行）——⭐ 正确且完整

  • Murphy 分解（Brier = Reliability − Resolution + Uncertainty）、ECE、Log-loss、Bootstrap 95% CI、climatology Brier Skill Score——预测科学四大标配齐全，且都做了空/单样本诚实返回。
  • 浮点分箱用 +1e-9 吸收舍入噪声（0.3×10=2.9999 的坑），工程细节到位。
  • 小样本（N<3）不报 CI——不制造精度错觉，这是论文级诚实。

1.4 技巧分 forecast-guard.ts（461 行）——⭐ 正确且有独立思想

  • climatology 基线 p(1-p) 替代误用的"抛硬币 0.25"，并指出"若某类事件 80% 发生，Brier=0.20 其实差于基线"——这是真正的预报科学素养（对标 GIFT-Eval / fev-bench 的 skill score 范式）。
  • normalizeDistribution 对位 TimesFM 的 fix_quantile_crossing——防止三情景概率越界/和≠1。
  • 新增的 k-NN analog coverage UQ 维度（覆盖度 ≠ 技巧分）是原创指标设计，有论文价值。

1.5 前瞻注册 commit-seal.ts（73 行）——⭐ 干净且是论文级卖点

  • sha256 封存"预测创建时载荷，不含结局"，排序规范化保证同义载荷同 hash。
  • 这是"可证明不马后炮"的密码学根基，全球预测产品极少做——是本项目最强的差异化与论文资产。

1.6 因果推理 causal-reasoning.ts（472 行）——⚠️ 假因果，论文红线

  • 仅定义 CausalNode/CausalLink 数据结构 + LLM 提示式"反事实"，全文无 do-calculus / 后门准则 / 可识别性 / 调整集 / 潜在结果。
  • 任何论文里若称其为"causal inference"，属学术不端。必须二选一：① 接 DoWhy/gCastle 做真因果（DAG 学习 + 识别），② 改名为"结构化因果式推理 / structured reasoning"。
  • 现状：工程可用、学术不可宣称。

1.7 情景合成 scenario-synthesizer.ts（500 行）——✅ 真计算但非新颖

  • 把多轮仿真共识分确定性映射为三情景概率（optimistic/neutral/conservative），并用 forecast-guard 修分位数交叉。
  • 是真实计算，但本质是线性映射，无方法新颖性，仅作系统组件。

1.8 测试质量——⭐ 论文级

  • conformal-prediction.test.ts：在 200 合成样本上断言边际覆盖 ≥ 1-1/(n+1) 精确下界（line 144-157, 209-224）——这是统计真值验证，不是凑覆盖率。
  • scientific-metrics.test.ts：常量 0.5→Brier 0.25、log-loss→ln(2)、完美预测→0——每个断言对应一个闭式真值。
  • 这两份测试是论文"可复现性"主张的直接证据。

3. SCI 可行性判定

3.1 能发，但 venue 要选对

Venue 类别 可行性 理由
核心 ML（ICML/NeurIPS/ICLR） ❌ 难 重实现≠新颖方法；需真方法贡献
UQ / Conformal 工作坊（ICML/NeurIPS workshop） ✅ 良 冷启动校准组合 + 覆盖保证是真实方法贡献
IJF（International Journal of Forecasting） ✅ 良 专业预测期刊，接受方法+实证
AIES / FAccT / CHI / CSCW（可信/人机） ✅ 良 sealed ledger + 人机校准是 HCI/伦理强卖点
Scientific Data / 元科学（PNAS meta-science） ✅ 良 数据集/基准论文，门槛看数据规模
Nature/Science 主刊 ❌ 需范式级发现，目前不具备

3.2 五个可落地论文选题（映射到现有资产 + 缺什么）

P1 · 密码学前瞻注册的可信预测系统（系统/元科学，最稳）

  • 资产：commit-seal.ts + OpenTimestamps 锚定 + 公开验证页（已有，但放错目录未部署，见查缺报告）。
  • 贡献：把"可证明不马后炮"做成可验证协议，应用于 crowd + human-AI 混合预测。
  • 缺：一个纵向部署研究（N≥200 条注册预测 + 结局回填 + 篡改抗性评估）。

P2 · 冷启动下的共形校准（UQ 方法，最有方法含量）

  • 资产：calibration.ts（经验贝叶斯收缩）+ conformal-prediction.ts（Split Conformal）。
  • 贡献：在 小样本/零样本 预测场景，把"经验贝叶斯先验收缩"与"分布无关覆盖保证"结合，给出诚实校准曲线。
  • 缺：在真实预测数据集（GDELT 历史事件 / Metaculus 问题）上与 Platt/MCP/未校准 LLM 做对比。

P3 · 覆盖度感知的技巧评分（指标/方法）

  • 资产：forecast-guard.ts 的 k-NN analog coverage UQ 维度。
  • 贡献：提出"技巧分 ≠ 全部"，用结构空间覆盖度作为独立不确定性信号。
  • 缺：在多个领域事件上验证"高 BSS + 低覆盖 = 不可信"的假设。

P4 · 神经符号可审计预测（前瞻，最冒险）

  • 资产：古典框架（八字）作为结构化领域启发式先验的接口（尚未实现）。
  • 贡献：把结构化人类领域先验作为可审计符号约束注入共形引擎。
  • ⚠️ 红线：必须框架为"structured domain heuristic prior"，绝不能宣称八字本身科学；否则整篇作废。建议立项前先咨询方法学审稿人。

P5 · 人机混合预测校准纵向基准（数据集论文，Scientific Data）

  • 资产：event-corpus + arena + sealed ledger = 天然基准底座。
  • 贡献：发布首个带密码学溯源 + 校准证书的人机预测基准。
  • 缺：语料 55 → 1000+、跑真实预测、回收结局。这是最吃力但最值钱的。

3.3 唯一阻断点与解锁路径

阻断：0 条已验证结局。 没有 (p,y) 真值对，P1/P2/P3/P5 都无法做实验。 解锁（前报告已给出，且成本最低）：

  1. 种子账号 + GDELT/历史新闻回填 300 条已发生事件（自带 ground truth）；
  2. 竞技场每日自动结算，新预测实时进 PredictionFeedback；
  3. 一次注入让 calibration / conformal / arena / scorecard 四个仪表盘同时有真数据——这不仅是地基，也是论文的数据底座。

4. 论文前的"学术诚信红线"（必读）

  1. 古典层不得作为科学先验宣称：八字/命理只能当"结构化人类启发式"，写完即声明其非科学属性。否则触雷。
  2. 因果层改名或升级：发稿前要么接 DoWhy/gCastle，要么改名为 structured reasoning，不得写"causal inference"。
  3. 所有准确率数字必须来自真实验证集：当前报告里的 Brier 0.136 / 83.3% 仅为 docstring 示例（见 scientific-metrics.ts:7,12,220），不能作为论文结果。
  4. 诚实降级要写进论文："零数据回 0.5""n<3 拒保证"是卖点不是缺陷，主动写。
  5. 复现包：测试 + 封存接口已具备，论文需附开源代码 + 数据快照（OpenTimestamps 锚定正好做 provenance）。
