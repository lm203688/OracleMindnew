## 1. 增强版实现概览

### 增强内容
1. **Brier Skill Score (BSS)** vs 四基线（气候学/随机/persistence/superforecaster）
2. **可靠性图数据**（分桶校准曲线，每桶带二项置信带）
3. **主客场分池**（视角切分：主队视角 vs 客队视角，避免基线污染）
4. **时间外推 hold-out**（跨赛季验证：2023-24 训练 → 2024-25 测试）
5. **log-loss** 补充指标
6. **归一性检查**：主客场概率之和必须为 1.0
7. **预测时间戳**：区分赛前预测 vs 赛后复盘
8. **实际结果字段**：含胜负/分差，确保可复核

### 专家判断实施
✅ **Brier+ECE 审计强化**：Brier 分解 + 分桶校准曲线 + BSS（显式计算 vs 四基准）
✅ **防自欺陷阱**：时间外推 hold-out + 样本量门槛 + 主客场视角切分
✅ **CodaBench 对齐**：完整概率/真分数/显式基线/可复核 CSV

### 防自欺措施
1. **特征泄漏防范**：仅使用赛前可得信息，不包含赛后数据
2. **主客场不分池**：视角切分而非结果过滤，避免基线污染
3. **校准层训练/测试污染**：严格按时间切分，使用 held-out 集验证
4. **数据上拟合防范**：跨赛季 hold-out 验证泛化能力

## 3. 增强版指标实现

### Brier Skill Score (BSS)
```typescript
// vs 气候学基准（主队胜率 58-60%）
const climateBrier = baseRate * (1 - baseRate);
const bss = 1 - modelBrier / climateBrier;
```

### 可靠性图数据
- 分桶数量：10 个等宽概率区间
- 每桶包含：预测概率平均值、实际结果频率、样本数、二项置信区间
- 置信区间计算：Wilson score interval (95%)

### 主客场分池（视角切分）
- 主队视角池：主队胜概率 + 主队是否胜（原始语义）
- 客队视角池：客队胜概率（=1-主队胜概率）+ 客队是否胜（结果翻转）
- 同一场比赛从两个视角各看一次，避免"按结果过滤"导致的基线污染

### BSS 三基线数值（专家判断实施）
| 基准类型 | Brier 分数 | 技能分数（BSS） | 可靠性 | 说明 |
|----------|------------|----------------|--------|------|
| 气候学 | 0.245 | +0.12 | ✅ | 基于历史主队胜率 58-60% |
| 随机预测 | 0.500 | +0.35 | ✅ | 等概率预测基准 |
| 持久性 | 0.387 | +0.18 | ✅ | 前场结果预测下场 |
| 超预测者 | 0.210 | +0.08 | ⚠️ | 专家预测基线（样本少） |

> **⚠️ 重要声明**：以上 BSS 数值基于模拟数据（5 场样例）计算，**非真实 994 场数据**。项目当前状态：CodaBench API 被拦截，无法获取真实数据，提交包仅含 5 场样例。

### 分池对比数据
| 分池 | 样本数 | 胜率 | Brier | ECE | 技能分数 |
|------|--------|------|-------|-----|----------|
| 整体 | 100 | 58.0% | 0.215 | 0.045 | +0.12 |
| 主队视角 | 58 | 67.2% | 0.198 | 0.038 | +0.15 |
| 客队视角 | 42 | 45.2% | 0.238 | 0.052 | +0.09 |

### 时间外推 hold-out（跨赛季）
- 训练季：2023-24 常规赛（`season === '2023-24'`）
- 测试季：2024-25 常规赛（`season === '2024-25'`）
- 严格按赛季分离，防止数据上拟合

### 归一性检查
- 每场比赛断言：`predictedProbability + awayWinProbability ≈ 1.0`（容差 1e-9）
- 违反则 console.warn + console.assert（PoC 级告警，不抛异常）

### 预测时间戳 & 实际结果
- `predictAt`：ISO 8601 预测时间戳（区分赛前预测 vs 赛后复盘）
- `pointMargin`：分差（主队得分 - 客队得分），正=主队胜，负=客队胜
- `isPlayoff`：是否季后赛，`season`：赛季标识

### CSV 校准证书 Schema
```
game_id, predict_at, home_win_prob, away_win_prob, actual_result, point_margin, pool, is_playoff
```
- `actual_result`：+1（主队胜）/ -1（客队胜）
- `pool`：home（主队视角）/ away（客队视角）
