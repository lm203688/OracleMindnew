## 方法对比

| 方法 | Brier | LogLoss | ECE | Acc |
|---|---:|---:|---:|---:|
| A. Flat 0.5（无信息） | 0.2500 | 0.6931 | 0.0279 | 0.472 |
| B. Category base rate | 0.2310 | 0.6544 | 0.0000 | 0.626 |

## 关键差值

**过度自信 LLM (D) → 温度缩放校准 (E)**
- Brier: `0.2432 → 0.2312` (Δ = **-0.0120**)
- ECE: `0.1010 → 0.0095` (Δ = **-0.0915**)
- 相对改善：ECE 降 **90.6%**，Brier 降 **4.9%**

## 解读

- **ECE 是"可信度"的直接度量**：0.10 → 0.01 意味着"我说 70% 时真的 70%"从 10% 偏差降到 1% 偏差。**这是 AnyJev/MAPIE 类校准层的直接价值锚**。
- **Brier 只降 4.9% 是因为过度自信与欠自信的 Brier 大致对称**：过度自信把 0.6 推到 0.7 时，Brier 增加量与把 0.6 推回 0.5 时的减少量相近。ECE 才是"是否校准"的敏感指标。
- **Category×horizon 基线 (C) 的 ECE 0.036** 是"用类别频率做预测"的天然校准上限。校准后的 LLM (E=0.0095) 能显著超越这个基线。

## 诚实标注的边界

**这份 dry-run 的三个真实限制**：

1. **我没有真的跑 sensechat / glm5.2 对这 305 个问题做预测**。方法 D 是我用 category base rate 施加一个 `p' = (p-0.5)*1.8 + 0.5` 的过度自信变换**模拟**的。真实 LLM 的偏差模式（是位置偏差、选项偏差、还是"总说 yes"）我并不知道。
2. **温度缩放只是 1D 优化**。真实的 AnyJev L0 层做**循环移位消位置偏差**（K 次 prefill），L1 层做**温度缩放 + 先验校正**（需要 100-500 条标签拟合）。我的简化版本没做位置偏差修正。
3. **ECE=0.0000 的 B 行是"作弊"的**：category base rate 是在训练集上算的（in-sample），部署时会有 in-sample-out 的 ECE 上升。C 行的 0.036 更接近真实上限。

**因此这份 dry-run 应该读作**："校准层理论能带来 90% 量级的 ECE 改善，方向确凿；但实际能兑现多少取决于真实 LLM 的偏差模式。"
